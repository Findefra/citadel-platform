# Azure AI Foundry

Azure AI Foundry (hub + project) built from two local modules:

- `modules/ai_hub` — storage account, Key Vault, and the AI Foundry hub
- `modules/ai_project` — a project inside the hub

The modules are reusable: point multiple projects at one hub, or deploy hubs per environment.

Migrated from `Findefra/azure-ai-foundry`.
