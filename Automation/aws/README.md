# Automation / aws

AWS-focused automation scripts (audits, CI/CD / Image Builder, ops, rollout).

Migrated from the `Automation_Scripts` repository.

## Layout

- `audits/` — Read-only quarterly inventory & compliance scripts (produce CSV reports)
- `cicd/` — EC2 Image Builder pipelines, launchers, Terraform helpers, lifecycle
- `ops/` — Backups, cleanup, unattached volume finders, MGN migration helpers
- `rollout/` — In-place ASG patching and related operational rollouts

See the original `Automation_Scripts` README for the full script catalog and usage notes.
